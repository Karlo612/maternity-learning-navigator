# Accessibility assessment plan

Target: WCAG 2.2 AA, without claiming certification.

Automated checks cover semantic landmarks, accessible names, colour contrast and common ARIA failures. Manual release tests cover keyboard-only operation, visible focus, 200% and 400% zoom, reflow at 320 CSS pixels, reduced motion, VoiceOver, form errors, offline state, English left-to-right layout and reviewed Sorani right-to-left/bidirectional layout.

Sorani rendering cannot pass until a qualified reviewer confirms text meaning, token order, punctuation and mixed-script behavior.
